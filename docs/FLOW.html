SwapUp — how a trade-in flows

Two devices at the counter: the advisor's (SwapUp Store) and the customer's phone (SwapUp Check). The SwapUp server, GradeIQ and Cashify work behind them. Every step below was checked against the code on 16 Oct 2026.

Once — set up the store

Store staff

Sign up in SwapUp Store

Join with an invite code from your manager (you become an advisor), or register a new store (you become its manager).

Register only works where the programme allows self-sign-up (demo programmes do). Otherwise the programme adds the store from the desk — it is live at once with its credit limit, and step 2 is skipped.
Programme

Approve the store, set its credit limit

Until then the store can test phones and see quotes, but cannot take a trade-in.

Store staff

Sign in · manager saves the store Wi‑Fi

Optional: the Wi‑Fi goes into a QR so a customer's phone can join and download the app. Without it, the customer uses mobile data.

Customer arrives

Advisor

New trade-in → QR + 6-character code

SwapUp opens a case (e.g. SU-AND-00010) and shows the test QR, the code (letters and numbers, valid 30 min) and the Wi‑Fi QR if saved.

Customer's phone

Scan → SwapUp Check

Android: install the app (Wi‑Fi or mobile data) or use the browser. iPhone: browser only. The browser version asks a few questions and guides each test; some tests can't run in a browser.

Test — the phone first, then photos

Customer's phone (Android app)

Tests start at once — no questions

Allow camera, mic and location, then it checks by itself: battery level, sensors, motion, network and GPS, speaker + mic, earpiece, vibration, flash, cameras; Bluetooth and NFC are checked as present. The customer only swipes every square, plugs in the charger (45 s, else "not tested") and lifts the phone if a camera asks.

Not tested automatically: buttons, multi-touch, fingerprint / face unlock, battery health — the advisor checks these.
Customer's phone
SwapUp Check

"Tests done — lay it on the counter"

Last step: shows the coloured screens the camera asks for.

Advisor's device
SwapUp Store GradeIQ

"Take photos"

Unlocks once the phone shows its photo screen. GradeIQ's AI looks for cracks, scratches and screen faults.

No advisor camera within 1 minute → "Finish without photos": the screen shows as not camera-checked. The advisor can still photograph the outside and checks the screen by eye. Browser checks never show the photo screen, so the advisor uses "Take photos anyway" with a reason.
Server GradeIQ Advisor

Results → "Apply to case"

Samsung model and storage fill in when the model code matches (otherwise pick by hand). Failed tests add faults. Camera damage is added only when GradeIQ's grade is final and at least 70% sure — anything weaker is a flag to check by eye. The camera's letter grade guides; it never sets the price.

Repair or upgrade?

Server

Repair price

Samsung India part prices + labour + 18% GST, with warranty / Care+ applied.

No automatic price for liquid, no power, frame or network faults, parts not in the price book, or non-Samsung phones — type the service centre's (or customer's) quote.
Cashify

Trade-in price

In this order: the amount typed from the Cashify app (with its reference) → Cashify live API (only with a signed contract) → Cashify's uploaded rate card → SAMPLE (cannot be used for a real trade-in).

Advisor

Pick the new phone · bonus worked out

The 2–5% bonus comes from the best running campaign (with any ₹ cap). A manager can change it within that campaign's band, with a reason.

Server

Recommendation

Repair costs half the new phone's price or more, or as much as the phone is worth repaired → leans upgrade. Repair 20% of a new phone or less, or it adds more value than it costs → leans repair. Both → "either". Covered by warranty / Care+ → repair. The bonus never counts.

Customer accepts

Advisor

Customer details + hand-over checks

Name, mobile, ID type and its last 4 characters (only those are stored). Customer owns it · SIM and card out · IMEI matches *#06# · no EMI / finance lock · government IMEI check (KYM, SMS to 14422).

Blocks: KYM flags the phone · IMEI already traded in · store not approved · not enough credit left for this trade-in · SAMPLE price in a real programme · quote expired · camera says it's a different phone (until a manager overrides).
Server

Trade-in locked — credit HELD

The trade-in value is held on the store's credit line. Customer pays new price − trade-in − bonus. Print the receipt and device tag.

Customer Advisor

Clear the customer's data

The customer signs out of Samsung + Google and factory-resets from Settings (SwapUp Check shows how). The advisor ticks what they saw: setup screen, no old-account prompt. Recorded as "not a certified erasure".

Pickup and settlement

Store manager

Book a pickup

Choose the waiting phones. Phones without a data-clear record are flagged (a warning, not a block).

Cancel: while a phone is not on a pickup (take it off first), a manager can cancel with a reason → full credit released.
Cashify

Schedule → collect

If the programme releases credit on collection, the hold is released here.

Cashify

Inspect each phone → verdict

Not receiveddispute

If credit releases on clearance, it's released here. A shortfall (trade-in − accepted) is charged to the store by default (a programme setting); "not received" always is. A chargeback stays on the line until a recovery is recorded.

Cashify

Settle with a payment reference

UTR and amount recorded. Settling doesn't move the credit line — that frees on collection or clearance.
